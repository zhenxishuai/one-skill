# One Distribute

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

## 前置检查

自行核对目标平台、具体稿件与版本、所需视觉资产、目标动作 draft / publish 及用户授权。已有明确内容不重复问。缺信息先从任务恢复；只有确实阻断投递的目标或版本才问。

正文无虚构事实、占位和未批准私人资料；所需视觉已有真实检查。发现可修复制作缺口，返回内容制作在授权范围补齐；不把子模块报错当整项任务结束。

## 草稿

用户要求 draft 时，用已授权且实际可用的连接或浏览器送入草稿箱。回读标题、正文锚点、资产与目标账号。记录 delivery 与实际回执，不写 published。会在未来自动公开的排期按 publish 处理。

## 公开

仅执行用户明确授权的具体平台和版本。授权未撤回且范围风险未变时沿用；内容版本变化重新确认。执行前检查目标账号、将发送内容与授权是否相同。

成功后核验真实公开页面或能证明公开的平台回执，回读标题、正文和资产，才登记 published。审核中记 submitted；普通上传成功不等于公开。记录系统登记与平台发帖是两种动作，不相互冒充。

## 失败与交付

超时或结果不明时先查平台现有状态，不能盲重试造成重复发布。无平台连接保留稿件和缺口，不虚构 URL 或 ID。只回读核验过的值，字段见 [记录模板](../one-skill/references/records.md)。

不自动私信、评论、群发、排期复盘或替用户承诺。发布授权不包含这些额外动作。
