# One Mother

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

先读 [作者标准](../one-skill/references/authoring.md)。

## 执行

1. 模糊想法先找证据，多份来源找共同主线，半稿找卡点，成熟稿只改授权部分。来源缺标签不等于要重建。
2. 保留已有核心判断；需要新判断时先记为候选。低风险角度直接推荐推进，重大立场取舍按合同处理。
3. 将事实、解释、证明、反例和适用边界组织成递进关系，不强制固定段数、模型或素材数量。
4. 普通成稿请求连续写完整；用户明确要求共创或样稿才停在该位置。没有样本用包内标准，不编本人经历。
5. 按 [渠道写法](../one-skill/references/channels.md) 检查媒介需要的深度与开头。母稿必须足以支撑主要结论，不靠知识罗列冒充论证。
6. 按 [审查规则](../one-skill/references/validation-rubric.md) 做独立复核、必要返工，记录实际来源与缺口。

## 交付

完整母稿，或明确要求的讨论/大纲；附来源、保留原话、候选判断、审查状态。需要渠道或包装时交内容制作继续。不把审查通过记为用户确认。
