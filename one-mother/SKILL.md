# One 共同论证底稿

先读 [共同约定](../one-skill/references/operating-contract.md)，沿用已有材料与停止位置。本模块整理共同依据，正文由内容制作完成。模块结束返回调用者；独立调用直接交付底稿。

## 执行

1. 区分原话、事实来源、已确认判断与候选主张。多份来源说同一件事只合并重复部分，保留相反证据、不同时间/对象/条件；不能把互相冲突的材料写成一致结论。
2. 用 [判断方法](../one-judge/references/judgment.md) 处理影响主张的概念、前提和推断。低风险角度直接建议；重大立场仍由用户决定。
3. 围绕主张组织证据和推理：哪份材料支持哪一句、支持到什么范围、推理中间还缺什么、什么反例会改变结论。资料多不等于论证成立。
4. 按读者接下来会追问的问题排顺序：先要理解什么，才能理解下一步。删去不承担作用的旁支；复杂题保留必要定义、机制、反例和边界，不强制固定层数。
5. 一句话想法或单一来源足够时，可直接形成简短论证依据；不要求每次另建底稿文件。只排版/发定稿不调用本模块。

## 交付与核验

交与材料复杂度相称的论证底稿：主张及其状态、原话与来源、推理顺序、不同意见和关键缺口。可复用现有笔记，不做字段齐全但没有内容的表格。

逐一核对主张是否有来源、推断是否明确、相反材料是否保留。只请求判断/底稿/大纲则到此结束；作为子模块时只返回底稿，由调用者继续已授权流程；由制作侧调用时不再调用制作。独立调用且明确要完整母稿、文章或多渠道成品时，交 [内容制作](../one-produce/SKILL.md) 沿用底稿写成对应正文，不停在交接提示词。此时“完整母稿”是制作产物，不是调用本模块的默认结果。
