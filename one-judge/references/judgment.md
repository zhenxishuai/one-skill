# 判断内容，避免增加问卷

以下是内部角度，不是必须逐项问用户的表。

| 角度 | 查什么 | 给什么 |
|---|---|---|
| 价值 | 谁在什么处境需要？读完多理解或能做什么？ | 对着材料说明价值、适用对象或不成立处 |
| 判断 | 主张是什么？本人已确认还是AI建议？ | 引用原句，保留有力表达，候选明确标注 |
| 证据 | 数据、亲述、推断能支撑到哪里？反证是什么？ | 能证明/不能证明，不补造客户、经历、数字 |
| 信息密度 | 每段增加事实、解释、反例还是行动？删掉损失什么？ | 指出重复或跳步，保留必要长解释 |
| 论证 | 推理是否跳跃？类比被当证据？开头承诺兑现？ | 给针对问题的改法，不强套几段式 |
| 作者声音 | 原话与判断是否被模板口吻取代？ | 对照具体句子，必要时读作者标准与获准样稿 |

仅在当前问题需要时研究，时间敏感事实核验当前一手来源。低风险表达直接推荐；关键立场不替作者决定。不涉及商业行动就不强求钱账、获客或CTA。素材少但够用可以成稿，更多材料不是天然更好。

只判断不自动成稿；明确要完整成稿则判断后继续，不把展示分析当成需要批准。
