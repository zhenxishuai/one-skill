# 对着原文把判断做实

只处理影响本次结果的问题。以下是内部工作步骤，不是开场问卷，不要求每篇跑全部研究、填写表格或获得阶段批准。

## 1. 把原句还原成具体的事

摘出要判断的原话，分清本人已确认立场与 Agent 建议。遇到“效率、价值、定位”等含义不清的词，写清谁在什么情境做什么、出现什么可观察变化。同词前后从“省时间”换成“交付更好”，就分开；删掉术语仍说不明白，指出缺的是对象、动作、结果还是关系，不直接给作者贴标签。

## 2. 判断材料能支持到哪里

把关键断言接回原始来源及上下文；多个转载同一事实不能当多个独立证据。检查是否把有时写成总是、先后或相关写成因果、一次经验写成普遍规律，或从一个结果倒推出唯一原因。

对实际有问题的断言给保留、收窄或重新解释的理由，并写出材料当前支撑得住的表述。证据不足只放下受影响断言，保留可用观察；来源冲突先比较时间、对象与条件，不挑最刺激的说法当真相。改变作者实质立场的修正标为候选，按共同约定请其决定，不冒充原话。

例如，测试夹具“这次用了 AI，报告提前交了，所以 AI 一定让所有团队更高效”：保留这次提前交付的观察；指出未排除其他因素、没有定义效率且不能推到所有团队。可用表述是“这次报告提前交了，过程中用了 AI；它具体节省了哪一步，还需对照前后流程”。不能补造工时、访谈或团队表现。

## 3. 看读者到底多理解了什么

用已有材料或获准对标判断：目标读者原先如何理解，本稿补充或纠正了什么，哪段证据或解释完成了这个变化。没有读者证据就标为工作假设，不冒称“大众都以为”。新增价值可以是澄清一个条件、解释一个原因、给出做法或展示真实例子，不强求反常识和商业 CTA。

逐段用一句话说出新增意思。相邻段只换词重复同一判断就合并；试删例子、定义、限制或过渡，删后读者需要自己补推理的，就保留或补清楚。信息密度衡量理解增加多少，不看字数少或术语多。

只有包装没有新内容时，指出具体空缺，从现有材料补实或缩小承诺。原话中有用的重复、犹豫、认识过程不能为了整齐删掉。

## 4. 按需要补机制、理论或对照

仅当用户请求，或关键解释缺支撑时研究。先把疑问说清：什么条件下，一个动作通过什么过程影响结果；再找支持、补充或反驳的最少充分来源。时间敏感事实查当前一手材料，不按人物、学科或案例数量凑齐。

理论核实原来解释的问题、原义与出处，区分原文、转引和本次解释。历史/行业类比比较处境、约束、行动与结果，说明相同处及可能破坏类比的差异；名字或行业相似不足以支持迁移。针对关键因果查另一种解释或反向结果，未找到就说明检索范围，不虚构反例。

结论区分充分支持、条件性启发和证据不足。仍需现实验证的解释，给一个可观察检查；材料已够或只是局部修改时不扩成研究报告。

## 5. 交能用的判断

指出“哪一句有问题 → 会造成什么误解 → 具体补、删或改什么”，并保留最值得留下的原话和未确定部分。只挑影响本次结果的地方，不默认展示全篇诊断表，不用抽象分数替代证据。

只判断就在该层交付；要复杂共同依据时交论证底稿；明确要完整成品则把可用表述、证据与限制交制作并继续。审题建议不是用户定稿，也不是制作的新批准门。
