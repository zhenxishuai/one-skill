# One Radar

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

## 执行

1. 看已有素材、账号目标和相关旧稿，判断读者正在面对的具体问题，避免重复包装旧判断。
2. 涉及新闻、人物、政策、产品变化时查当前一手来源与时间。没有来源就标缺失，不编热度和互动数。
3. 逐题用 [判断方法](../one-judge/references/judgment.md) 检查具体价值和证据。选题时另查作者是否已经讲过同一判断，本次新增了什么。
4. 内容若服务于商业行动，核对问题、证明、下一步与实际承接；认知与信任稿允许不推产品。企业题看业务后果，其他题不强套企业框架。
5. 按请求给候选数量，未指定时给一个最有依据的推荐；只有取舍确有差异才补备选，不设覆盖用户请求的固定上限。每项附受众、判断候选、来源与日期、载体、反例和缺口。
6. 只要审题则到此结束；同时要正文则交内容制作沿用本次判断继续成稿。无合格题时交已查范围与缺口，不凑数量。

## 验证

推荐有材料依据；候选判断与用户立场分开；没有虚构趋势、自动定位或未经请求的成稿。按 [通用用例](../one-skill/references/case-pack.md) 检查范围。
