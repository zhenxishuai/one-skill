# One 内容制作

接住材料或已确定内容，完成本次成品。能力增加只扩展对应操作说明和可选绑定，不把平台细节堆进本入口。

## 执行

1. 读 [共同约定](../one-skill/references/operating-contract.md)，从现有材料取得原文、版本、保留项和所需成品。独立调用直接提取，不强制先判断或先母稿。
2. 按 [能力目录](references/capabilities.md) 只选本次动作。一般缺省风格和数量按材料/模板决定，不启动菜单。写稿才读作者和渠道规则；只排版/发送不改正文。
3. 有用户配置的专项Skill时读其主文件和必需引用，传入既定内容、范围和授权；没有绑定按包内操作说明使用宿主能力。文件存在不等于工具或平台连接可用。
4. 直接完成产物。编辑句子/段落属于制作；需要新增立场、改变事实或补重大论证时，只将该问题和必要上下文交给 [内容判断](../one-judge/SKILL.md)，回来继续，禁止整篇无条件重跑。不编造事实。
5. 做到本次层级就验收：只排版不追加选题、生图、投递；要完整图文/拍摄包就做齐，不把操作提示词当成品。外部动作遵守 [投递与发送](references/delivery.md)。

## 专项能力边界

专项Skill只提供执行方法；默认问卷、固定配色、页数/字数定额、标题矩阵、知识库回写或发布步骤不扩大本次范围。沿用已确认文字、风格与授权；事实、隐私、明确批准门和宿主限制仍有效。

所选能力的明确前置条件无法满足时，不伪填已确认/已审或更改账号/知识库状态。保存产物，使用已有授权且满足同等验收的路径；仍不可用就只报告该环节缺口。

## 核验与交付

按 [验收标准](../one-skill/references/validation-rubric.md) 检查当前产物：文字对照原文，视觉实际打开，排版查手机阅读与复制，发送读回目标/内容/回执。完整主观成品做独立/隔离复核，缺审标未审；文件生成、复制或上传成功不等于平台验收/公开。

按 [轻量交接](../one-skill/references/handoff.md) 和 [记录字段](../one-skill/references/records.md) 复用已有记录，小修可在对话完成。交实际产物、已验范围与缺口；升级回放 [用例](../one-skill/references/case-pack.md)，工具未调用不记成功。
