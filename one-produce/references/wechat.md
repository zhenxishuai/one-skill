# 公众号配图与排版

封面、正文图、排版分别可用，只做所请求部分。先读 [设计规范](../../one-design/SKILL.md)，有本地绑定才按需加载专项Skill，沿用品牌与已定文章，不强塞配色或卡片数量。

## 封面与正文图

- 封面核心词/主体在缩略图与分享裁切中仍可识别；横版比例、尺寸和裁切行为以当前环境核实，不把旧规格当永久标准。
- 制作完整图与对应裁切预览，实际打开核对标题、核心词、主体与边缘。短封面文案可忠实缩写，不改变承诺。
- 场景图走 [场景配图](../../one-image/SKILL.md)，不得冒充真实客户现场。逻辑/数据图用准确图形表达真实关系，不虚构数据、效果与箭头。
- 文字生不准改准确文字层；留实际文件、必要源文件和检查结果。

## 整篇排版

1. 锁住原文、顺序、引用、数字和结论，只调整标题层级、段落和图文间距。既有风格沿用，无风格按内容选可读默认，不先问菜单。
2. 优先静态HTML或既有排版环境，提供手机预览；需要复制时实现富文本/纯文本复制，不为一篇文章新建应用框架。
3. 正文用目标编辑器支持的内联样式；工具栏、脚本和按钮留在预览壳，不能混进文章。重要内容不依赖外部字体、交互或滚动小窗。
4. 本地实际打开查完整正文、图片、长段落、表格与溢出，测试复制。复制返回成功不代表已贴入公众号；平台保真须在真实编辑器核对。
5. 本地排版交HTML、资产与预览结果；用户要求草稿箱才转 [投递与发送](delivery.md)。未做目标验收时标本地已验、平台兼容未验。

## 排版前后对照

保留原文副本，逐段核对导出 HTML 的可见正文：字、数字、单位、引用、链接目标和顺序；允许排版空白变化，不允许为了美观改论点。长引用、表格和图片说明单独检查，不能因隐藏、折叠或滚动区而漏掉。

正文复制区只包含文章及相关资产，不包括预览按钮、状态说明或审稿记录。浏览器可见的本地图片并不一定能在公众号显示；平台草稿路径必须使用该平台支持且已授权的资产导入，并在实际编辑器回读图片，不能留下本地绝对路径或失效链接。

本地成品交自包含文件或 HTML 加资产文件夹，写清依赖关系；文字未变的纯样式修正复核受影响页面，不启动全文价值审问。
