# 小红书封面与组图

先读 [设计规范](../../one-design/SKILL.md)，按需加载已绑定的封面/内页Skill。保留原文事实、标题原意与用户模板，数量按内容，不强制6–9页、固定颜色、emoji或水印。

1. 封面表达一个清楚的内容承诺；已有标题沿用，没有则选一个忠实的短标题，不要求先选标题/风格菜单。
2. 组图先建立原文要点到各页的对应关系，一页一个主要作用，整体完整。单封面不额外做内页或选题报告。
3. 分清主体图、背景图、风格参考。先查看获准图片，保留人物/产品特征，不复制参考的身份、品牌签名与独有素材；平台比例/尺寸/文件要求在实际投递时核实。
4. 生图实际调用宿主原生工具并服从其编辑/引用规则。精确长文字用可编辑排字；生图文字不可靠时改无字底图加准确文字层，不缩小字号掩盖问题。
5. 逐页打开查文字、数字、缩略可读性、主体、边距、页序和风格；对照原文关键条件。可编辑方案同时查源文件与导出图，不能只交提示词。
6. 交图片、实际尺寸、页序与必要源文件，说明检查范围。无生图/渲染保留设计与内容，标视觉未完成。

做好图文不自动投递。明确要发才转 [投递与发送](delivery.md)。
