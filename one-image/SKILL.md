# One Image

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

## 输入与执行

1. 核对用途、读者、画幅、主体、必须出现/不得出现项和输出位置。设计依据缺失时先读 [one-design](../one-design/SKILL.md) 形成版式与品牌标准。
2. 将内容变成一个具体可理解的场景，人物与工作环境可信，构图克制。不要堆抽象 AI 符号、随机渐变或装饰性立体卡片。
3. 使用当前宿主允许的原生生图/编辑工具。有参考图按授权使用；涉及可识别真人或客户材料核对本次授权。不得为生成服务外发未获准的私人资料。
4. 生成图仅为说明性画面，不冒充客户、本人亲历或成果证据。需要精确大段文字时交回设计模块排字。
5. 打开结果检查构图、尺寸、人物、文字伪影和一致性。同一失败机制重复时停止盲试，改用已授权可行方案并保留结果；不按固定次数收工，不绕过限制。

## 验证与交付

交实际图片、尺寸、设计依据、视觉检查和剩余问题。无生图能力只能交设计说明；无视觉回读不能报告视觉通过。按 [审查规则](../one-skill/references/validation-rubric.md) 保留公开授权门。
