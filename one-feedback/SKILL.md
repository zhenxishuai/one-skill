# One Feedback

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

## 执行

1. 看原内容、平台、时间窗口与来源。正式登记反馈前核验公开状态；只有截图也可做定性分析，但标待核实，不改发布状态。
2. 依本次目标读数据：认知看理解与追问，信任看收藏转发和具体回应，行动看目标对话及下一步。没有成交目标不按私信数否定内容。
3. 未提供的指标记 unavailable；不同平台的数字不直接横比。有效线索须同时有人或组织、具体问题、明确下一步，泛泛想聊不能计入。
4. 寻找证据最强的上游断点：触达、停留与承诺兑现、目标匹配、业务承接。没有数据就保留多种可能，不宣布限流或因果。
5. 单篇看其具体内容与数据；账号分析需要多篇同口径数据、时间窗口和受众信息，不从一条反推全部定位。
6. 只给下一次一个可观察改变，注明原文/评论/数据依据、保持哪些条件、比较哪个同口径指标或具体反馈，以及结果不符时先撤回哪个解释。没有可比样本先记观察，不预设限流、成交因果或万能阈值。48 小时或 7 天仅在用户请求时作为窗口，不自动创建提醒。

## 验证与交付

给来源、指标、结论边界、第一断点和下次实验。配置且获准写回时复用真实记录并读回，否则交本地报告。一次反馈只是观察，同类至少三次才成规则候选；长期规则采纳仍需用户批准。字段见 [记录模板](../one-skill/references/records.md)。
