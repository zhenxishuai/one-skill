# 本地配置与运行条件

本包是给具备文件阅读能力的 AI 助手加载的工作规则，不是独立运行的应用。文字任务需要宿主模型和用户材料；文件写入、联网查证、独立审查、生图与平台操作取决于宿主实际工具。

## 无配置起步

完整下载仓库，在对话里给出 one-skill/SKILL.md 的实际路径并要求加载。助手应继续读取所需相对引用，使用本轮材料与包内规则。默认只产出本地待审内容，不连接平台。若宿主不能读目录，需附上主文件、运营合同、作者标准、对应渠道与审查文件；只有 README 不够。

## 可选配置

复制仓库根的 config.example.json 为 config.local.json，在本地填写。运行时明确告诉助手配置文件位置。配置由助手读取并解释，不是自动执行程序。相对路径相对于配置文件目录，未设置字段按默认值处理；发现不存在路径报告该项并继续独立可做的工作。

- author_samples：已获准用于本次写作的样稿文件路径列表，只抽取声音，不借用人生事实。
- knowledge_paths：本次允许检索的文件或目录列表；空列表表示只用用户材料和允许查证的来源。
- output_dir：本次本地输出目录；无配置默认当前任务 outputs/one-test/。真实素材和输出须在公开仓库外或已忽略且未跟踪的目录，复用已有项目，不覆盖无关文件。
- preferred_writing_model：偏好名称；仅在实际入口支持且材料允许使用时调用。空值使用当前模型。
- connections：用户已配置的连接名称/目标，不放密钥。knowledge、board、publisher 均可为空。填写后仍须核对目标、权限与本次授权，不能因此自动发送。

账号授权在宿主的连接器或凭据管理中完成。不要把 token、cookie、密码、私人样稿或知识库复制进仓库。config.local.json、private/ 与 outputs/ 已被忽略，但忽略规则不能代替上传前检查。

## 外部能力

没有知识库：从用户材料写，不假称召回。
没有指定模型：按合同透明降级；明确不接受替代则报告调用受阻。
没有文件工具：在对话交付文本并标未落盘。
没有独立 reviewer：完整草稿可交，标缺独立审查。
没有生图/渲染：保留内容和设计说明，视觉仍未完成。
没有平台连接：保留可用稿件及投递缺口，不假称已送入草稿箱。

## 隔离测试与启用

下载、阅读与测试本包不修改已安装 Skill。建议先用独立对话显式加载这份候选，输出到独立目录。若以后决定安装，需要把八个 One 目录作为同级目录整体放入宿主支持的 Skill 位置，保持相对引用；放置前检查旧版本、备份和激活门禁。本轮不执行安装。

本包尚无正式激活批准，原指定 skill_gate 缺失也未取得替代门禁的批准。结构检查通过只支持继续隔离评估，不得自行当作正式启用许可。
