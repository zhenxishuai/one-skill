# One Adapt

先读 [运营合同](../one-skill/references/operating-contract.md)，采用同一任务的材料、已确认项和停止位置。模块结束后返回调用它的内容判断/内容制作入口；独立调用直接交付，不反向加载总入口。

先读 [作者标准](../one-skill/references/authoring.md) 与 [渠道写法](../one-skill/references/channels.md)。

## 执行

1. 读取原文、共同来源、保留段落、已核实事实和目标平台。关键事实未核验先处理；改编不能洗掉缺口。
2. 一个平台做一个，多个按请求做齐。平台未指定时根据材料推荐一个并说明假设，重大方向歧义按合同处理。
3. 每版从同一原始来源派生，记录父稿与版本关联；不逐层用改编稿代替来源。父稿未确认也可制作明确待审版，不伪造父稿 approved。
4. 依包内渠道写法重做开头、结构和节奏。保留判断和事实；短版交代删减范围，不声称保留被删的完整论证。
5. 每版做原文保真与渠道审查。请求视觉才进入 [one-design](../one-design/SKILL.md)，纯文字不添加视觉门。
6. 已连接的记录系统若拒绝当前状态，保留本地派生稿与待登记信息，不更改父稿批准状态或绕过工具限制。

## 验证与交付

数量符合请求、版本可独立阅读、来源可追溯、无新增经历和模板人格。交实际版本及审查结果、登记缺口，不自动投递。
